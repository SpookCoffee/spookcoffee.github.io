# SpookCoffee root homepage

This project is hosted at **https://spookcoffee.github.io/**.

The page deliberately uses the **original simple Graphite + Wine design**, with:

- Portfolio — Coming Soon (wine-red, not clickable yet)
- Contact-ID (dark button linking to the live contact card, labeled v0.2.0 Beta)
- Root-site footer — Beta v1

## Publish with VS Code

Copy `index.html` and `.nojekyll` into the root of the `SpookCoffee.github.io` repository. Preview the site locally, commit and push to the branch GitHub Pages publishes (normally `main`).

The page uses no external scripts, analytics or fonts.
